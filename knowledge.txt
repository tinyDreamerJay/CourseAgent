云计算是通过网络按需提供计算资源（服务器、存储、数据库、网络等）的模式，用户无需自己购买和维护物理设备，按实际使用量付费。它具有按需自助服务、广泛网络访问、资源池化、快速弹性、可计量服务五个基本特征。

云计算有三种服务模式：IaaS（基础设施即服务）提供虚拟机、存储、网络等底层资源，用户自己安装操作系统和软件，典型如阿里云 ECS；PaaS（平台即服务）提供运行环境和开发工具，用户只负责写代码；SaaS（软件即服务）直接提供可用的软件，如企业邮箱、在线文档。

虚拟化技术是把一台物理服务器划分成多个相互隔离的虚拟机。核心组件是 Hypervisor（虚拟机监控程序），它负责分配 CPU、内存、磁盘等资源。虚拟化的好处是提高硬件利用率、降低成本和便于快速部署。

容器与虚拟机的区别：虚拟机包含完整的操作系统，启动慢、占用资源多；容器共享宿主机内核，只打包应用和依赖，启动只需秒级、占用资源少。Docker 是最常用的容器工具，用镜像描述应用环境，用容器运行实例。

Kubernetes 是容器编排平台，用于管理大规模容器集群。核心概念包括：Pod 是最小调度单位，可以包含一个或多个容器；Service 为一组 Pod 提供固定访问入口；Deployment 负责 Pod 的滚动更新和副本数管理。

负载均衡是把大量请求分发到多台服务器上，避免单台服务器过载。常见算法有轮询、加权轮询、最少连接数、IP 哈希。工作在传输层的是四层负载均衡如 LVS，工作在应用层的是七层负载均衡如 Nginx。

弹性伸缩是指根据实际负载自动增减服务器数量。负载上升时自动增加实例保证性能，负载下降时自动减少实例节省成本。实现方式通常是监控 CPU、内存或请求量等指标，触发预设的扩缩容规则。

云存储分为三种类型：对象存储适合存放图片、视频、备份等非结构化数据，通过 HTTP 接口访问，容量几乎无限；块存储相当于一块虚拟硬盘，需要挂载到服务器上使用，适合数据库；文件存储提供共享目录，多台服务器可以同时读写。

CDN 即内容分发网络，它把静态资源缓存到离用户最近的边缘节点，用户请求时直接从就近节点返回，减少网络传输距离，加快访问速度。适合加速图片、视频、静态网页等不常变化的内容。

微服务架构是把一个大型应用拆分成多个独立部署的小服务，每个服务只负责一项业务能力，通过 HTTP 或消息队列通信。优点是便于独立开发部署和扩容，缺点是运维复杂，需要处理分布式事务和网络故障。

TCP 建立连接的三次握手：客户端发送 SYN 报文请求连接；服务器回复 SYN 加 ACK，同意连接并请求反向连接；客户端再回复 ACK 确认。三次握手的目的是让双方都确认对方的收发能力正常，并同步初始序列号。

TCP 断开连接的四次挥手：主动方发送 FIN；被动方回复 ACK；被动方处理完剩余数据后再发送 FIN；主动方回复 ACK 并等待 2MSL 后关闭。因为 TCP 是全双工的，两个方向要分别关闭。

TCP 与 UDP 的区别：TCP 面向连接、可靠传输，有确认重传和流量控制机制，适合文件传输和网页浏览；UDP 无连接、不保证可靠，但开销小、延迟低，适合视频直播、语音通话和 DNS 查询。

HTTP 与 HTTPS 的区别：HTTP 是明文传输，数据可能被窃听和篡改；HTTPS 在 HTTP 之下增加了 TLS 加密层，对传输内容加密并验证服务器身份。HTTPS 默认端口是 443，HTTP 默认端口是 80。

DNS 解析过程：浏览器先查本地缓存和 hosts 文件；如果没有，则向本地 DNS 服务器发起递归查询；本地 DNS 依次向根域名服务器、顶级域名服务器、权威域名服务器查询，最终得到 IP 地址并逐级缓存。

IP 地址与子网掩码：IPv4 地址是 32 位二进制数，通常写成点分十进制形式如 192.168.1.1。子网掩码用来划分网络号和主机号，例如 255.255.255.0 表示前 24 位是网络号。同一子网内的主机可以直接通信，跨子网需要经过路由器转发。

数据库的三大范式：第一范式要求每个字段都是不可再分的原子值；第二范式要求非主键字段完全依赖于主键，不能只依赖主键的一部分；第三范式要求非主键字段不能传递依赖于主键。

索引是加快数据检索速度的数据结构，常见的有 B+树索引和哈希索引。B+树索引支持范围查询和排序，哈希索引只支持等值查询。索引会占用额外的存储空间，并且会降低插入、更新、删除的速度。

事务的 ACID 特性：原子性指事务内的操作要么全部成功要么全部失败；一致性指事务前后数据的完整性约束不被破坏；隔离性指并发事务之间互不干扰；持久性指事务提交后的修改永久保存。

进程与线程的区别：进程是操作系统分配资源的基本单位，拥有独立的地址空间；线程是 CPU 调度的基本单位，同一进程内的线程共享内存和文件句柄。线程切换的开销比进程小，但一个线程崩溃可能影响整个进程。
